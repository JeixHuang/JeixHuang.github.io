SWE-Shift: Evaluating Coding Agents in Evolving Workspaces

Victor Shea-Jay Huang, Rongqing Li, Zhangyue Yin, Kelong Mao, Yaqi Zhao, Xinyuan Wang, Yao Yin, Lirui Luo, Renrui Zhang, Hongsheng Li

arXiv ↗ PDF ↗ Code ↗ Citation ↘

TL;DR

A benchmark for coding agents facing mid-execution changes. Across 120 scenarios and 12 change families, all 17 evaluated systems have lower success after the workspace changes.评测 Coding Agent 在执行过程中应对变化的能力。覆盖 120 个场景、12 类变化，17 个受测系统在工作环境变化后的成功率均下降。
